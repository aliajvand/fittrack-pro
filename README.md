# FitTrack Pro — پلتفرم چندکاربره برنامه ۳۰ روزه تمرین، تغذیه و خروجی تحلیل AI

این پروژه به‌صورت اختصاصی برای **Cloudflare Pages + Cloudflare D1 + سرویس پیامکی SMS.ir** طراحی شده است (بدون نیاز به سرور جداگانه و با هزینه رایگان در پلن Free کلودفلر).

---

## امکانات اصلی
- **احراز هویت چندکاربره با پیامک (SMS.ir OTP):** هر کاربر با شماره موبایل وارد حساب اختصاصی خودش می‌شود (دارای محدودیت تعداد ارسال، هش SHA-256 کد تأیید و نشست امن JWT HttpOnly).
- **ذخیره‌سازی ابری در Cloudflare D1:** هر فرد پروفایل، برنامه شخصی‌سازی‌شده، تیک‌ها، وزنه‌ها، تغذیه و یادداشت‌های روزانه خودش را دارد و از هر گوشی یا لپ‌تاپی که وارد شود، اطلاعاتش همگام است.
- **ویرایشگر برنامه شخصی:** امکان انتخاب از ۳ قالب آماده (باشگاه+کلیستنیکس، تمرین خانگی، یا قالب خالی) به همراه افزودن و حذف حرکت در هر روز.
- **منوی غذایی ۳۰ روزه + ثبت خوراکی دلخواه:** محاسبه زنده کالری و پروتئین روزانه.
- **سنجش آمادگی (خواب + بدن‌درد + انرژی) + قانون نمره ۷:** قفل خودکار تمرین سبک سینه هنگام بدن‌درد شدید و کلید تبدیل پنج‌شنبه به حالت سبک ریکاوری.
- **نمودارهای تحلیلی SVG:** روند وزن ناشتا، پایبندی پروتئین روزانه و جدول پیشرفت رکورد حرکات (PR Tracker).
- **استودیو خروجی هوش مصنوعی (AI Export):** تولید پرامپت مهندسی‌شده (۳ سبک مختلف) + دانلود `.md`، `.json` و `.csv` برای ارسال مستقیم به Gemini / ChatGPT / Claude.
- **قابل نصب روی گوشی (PWA):** پس از باز کردن سایت در گوشی، با گزینه Add to Home Screen مثل اپلیکیشن نصب می‌شود.

## راهنمای گام‌به‌گام استقرار روی Cloudflare Pages

### مرحله ۱: آماده‌سازی قالب پیامک در پنل SMS.ir
1. وارد پنل **SMS.ir** شوید و به بخش **ارسال سریع (Verify / الگوها)** بروید.
2. یک الگوی جدید بسازید، مثلاً:
   `کد ورود شما به FitTrack Pro: #CODE#`
3. پس از تأیید الگو، عدد **شناسه قالب (Template ID)** را یادداشت کنید (برای تست در حالت سندباکس SMS.ir معمولاً شناسه `100000` است).

> **نکته امنیتی مهم:** هرگز `SMSIR_API_KEY` را مستقیم داخل کدهای GitHub ننویسید. فقط در بخش Environment Variables داشبورد کلودفلر وارد کنید.

---

### مرحله ۲: ساخت دیتابیس Cloudflare D1
در ترمینال سیستم خود (داخل پوشه پروژه):

```bash
npm install
npx wrangler login
npm run db:create
```

خروجی ترمینال یک `database_id` به شما می‌دهد. آن را داخل فایل `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_D1_DATABASE_ID` کنید.

سپس جداول دیتابیس را روی کلودفلر بسازید:

```bash
npm run db:migrate:remote
```

---

### مرحله ۳: دیپلوی روی Cloudflare Pages
دو روش دارید:

#### روش الف (سریع‌ترین — مستقیم با Wrangler):
```bash
npm run deploy
```

#### روش ب (اتصال به GitHub — پیشنهادی):
1. پروژه را در یک ریپازیتوری خصوصی (Private) گیت‌هاب پوش کنید.
2. در داشبورد کلودفلر خودتان وارد **Workers & Pages -> Create -> Pages -> Connect to Git** شوید.
3. تنظیمات Build را به این شکل بگذارید:
   - **Framework preset:** `None`
   - **Build command:** *(خالی بگذارید)*
   - **Build output directory:** `public`

---

### مرحله ۴: اتصال دیتابیس D1 و تنظیم کلیدهای امنیتی در داشبورد کلودفلر
در داشبورد کلودفلر وارد پروژه Pages خود شوید -> تب **Settings**:

1. در بخش **Bindings (یا Functions -> D1 database bindings)**:
   - Variable name: `DB`
   - D1 database: `fittrack-db`
2. در بخش **Variables and Secrets (Environment variables)** این متغیرها را به حالت **Encrypt (Secret)** اضافه کنید:
   - `SMSIR_API_KEY` = کلید API پنل SMS.ir شما
   - `SMSIR_TEMPLATE_ID` = شناسه قالب Verify شما (مثلاً `100000` یا شناسه قالب تاییدشده)
   - `SMSIR_PARAM_NAME` = `CODE`
   - `JWT_SECRET` = یک رشته تصادفی حداقل ۳۲ کاراکتری (مثلاً `f9K2mP8xQ4vR7nL1wZ6cB3yT5hJ0dS9a`)
   - `DEV_MODE` = `false` *(در صورت نیاز به دیدن کد OTP روی صفحه بدون مصرف شارژ پیامک، موقتاً `true` بگذارید)*
3. پس از ذخیره متغیرها، یک بار پروژه را **Retry deployment** (یا `npm run deploy`) کنید تا تنظیمات اعمال شود.

## اجرای لوکال روی سیستم خودت (تست قبل از انتشار)
```bash
cp .dev.vars.example .dev.vars
# مقادیر را داخل .dev.vars وارد کن
npm run db:migrate:local
npm run dev
```
سپس مرورگر را روی آدرسی که Wrangler نشان می‌دهد (معمولاً `http://localhost:8788`) باز کن.
